Hiperbólicas Inversas

Las funciones hiperbólicas inversas ($\operatorname{senh}^{-1}$, $\cosh^{-1}$, $\tanh^{-1}$) se pueden escribir con logaritmos, y aparecen al integrar $\frac{1}{\sqrt{u^2 \pm a^2}}$ y $\frac{1}{a^2 - u^2}$.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Con $a > 0$ y $u = g(x)$:

$$\int \frac{du}{\sqrt{u^2 + a^2}} = \ln\left(u + \sqrt{u^2 + a^2}\right) + C = \operatorname{senh}^{-1}\frac{u}{a} + C$$ $$\int \frac{du}{\sqrt{u^2 - a^2}} = \ln\left|u + \sqrt{u^2 - a^2}\right| + C \qquad (|u| > a)$$ $$\int \frac{du}{a^2 - u^2} = \frac{1}{2a}\ln\left|\frac{a + u}{a - u}\right| + C = \frac{1}{a}\tanh^{-1}\frac{u}{a} + C \qquad (|u| < a)$$
¿Por qué logaritmos? $\operatorname{senh} y = \dfrac{e^y - e^{-y}}{2}$ es una combinación de exponenciales; al despejar $y$ en $x = \operatorname{senh} y$ aparece $\ln$. Por eso en un examen puedes dejar la respuesta con $\ln$ o con la función inversa.

El procedimiento es el mismo de siempre: identifica $a$ y $u$, calcula $du$, aplica la fórmula y regresa a $x$.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Las tres antiderivadas son logaritmos disfrazados. Por ejemplo $\operatorname{senh}^{-1}x = \ln(x + \sqrt{x^2+1})$ crece muy despacio, igual que $\ln$.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo XII.1 — $\displaystyle\int \frac{dx}{\sqrt{x^2 + 9}}$

  1. Tiene la forma $\sqrt{u^2 + a^2}$ con $a = 3$ y $u = x$ ($du = dx$).
  2. Aplicamos la fórmula: $$\int \frac{dx}{\sqrt{x^2 + 9}} = \ln\left(x + \sqrt{x^2 + 9}\right) + C$$
  3. Comprobación: $\dfrac{d}{dx}\ln\left(x + \sqrt{x^2+9}\right) = \dfrac{1 + \frac{x}{\sqrt{x^2+9}}}{x + \sqrt{x^2+9}} = \dfrac{1}{\sqrt{x^2+9}}$ ✔

$\displaystyle \ln\left(x + \sqrt{x^2 + 9}\right) + C = \operatorname{senh}^{-1}\frac{x}{3} + C$

Ejemplo XII.2 — $\displaystyle\int \frac{dx}{1 - 4x^2}$

  1. Tiene la forma $a^2 - u^2$ con $a = 1$ y $u = 2x$, así $du = 2\,dx$ y $dx = \tfrac12\,du$.
  2. Sustituimos: $$\frac12\int \frac{du}{1 - u^2} = \frac12\cdot\frac{1}{2}\ln\left|\frac{1 + u}{1 - u}\right|$$
  3. Volvemos a $x$: $\displaystyle\int \frac{dx}{1 - 4x^2} = \frac14\ln\left|\frac{1 + 2x}{1 - 2x}\right| + C$.
  4. Comprobación: $\dfrac{d}{dx}\,\dfrac14\left[\ln|1+2x| - \ln|1-2x|\right] = \dfrac14\left[\dfrac{2}{1+2x} + \dfrac{2}{1-2x}\right] = \dfrac{1}{1 - 4x^2}$ ✔

$\displaystyle \frac14\ln\left|\frac{1 + 2x}{1 - 2x}\right| + C$
