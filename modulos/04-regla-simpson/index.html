Regla de Simpson

El paso siguiente después de rectángulos y trapecios: aproximar la curva con parábolas. Cada parábola pasa por tres puntos de la curva y cubre dos subintervalos.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Tomamos los subintervalos de dos en dos. Por los tres puntos $(x_{i-1}, f(x_{i-1}))$, $(x_i, f(x_i))$ y $(x_{i+1}, f(x_{i+1}))$ pasa exactamente una parábola, y el área bajo esa parábola se puede calcular de forma exacta:

$$\int_{x_{i-1}}^{x_{i+1}} p(x)\,dx = \frac{\Delta x}{3}\big[f(x_{i-1}) + 4f(x_i) + f(x_{i+1})\big]$$

Sumando todas las parábolas se obtiene la regla de Simpson, con coeficientes $1, 4, 2, 4, 2, \dots, 4, 1$:

$$S_n = \frac{\Delta x}{3}\left[f(x_0) + 4\sum_{i\ \text{impar}} f(x_i) + 2\sum_{i\ \text{par}} f(x_i) + f(x_n)\right]$$
$n$ debe ser par, porque cada parábola necesita dos subintervalos. Por eso el deslizador de este módulo avanza de 2 en 2.

Su error depende de la cuarta derivada, así que Simpson es exacta para polinomios de grado 3 o menor (su cuarta derivada es cero):

$$|E_S| \le \frac{K(b-a)^5}{180\,n^4}, \qquad K = \max|f^{(4)}(x)|$$

3 Ejemplos resueltos paso a paso

Ejemplo IV.1 — $\displaystyle\int_0^2 x^2\,dx$ con $n = 4$

  1. Ancho: $\Delta x = 0.5$, así que $\dfrac{\Delta x}{3} = \dfrac{1}{6}$.
  2. Valores: $f(0)=0$, $f(0.5)=0.25$, $f(1)=1$, $f(1.5)=2.25$, $f(2)=4$.
  3. Coeficientes: $1, 4, 2, 4, 1$.
  4. Aplicamos la fórmula: $$S_4 = \frac{1}{6}\big[0 + 4(0.25) + 2(1) + 4(2.25) + 4\big] = \frac{1}{6}\,(0 + 1 + 2 + 9 + 4) = \frac{16}{6} = \frac{8}{3} \approx 2.6667$$
  5. ¡Coincide exactamente con $\int_0^2 x^2\,dx = \frac{8}{3}$! No es casualidad: $x^2$ es un polinomio de grado $2 \le 3$, así que la parábola ajustada es la propia curva y el error es cero.

$S_4 = \frac{8}{3} \approx 2.6667$: resultado exacto, error $0$.

Ejemplo IV.2 — $\displaystyle\int_1^3 \frac{1}{x}\,dx$ con $n = 4$

  1. Ancho: $\Delta x = \dfrac{3-1}{4} = 0.5$, así que $\dfrac{\Delta x}{3} = \dfrac{1}{6}$.
  2. Nodos: $1$, $1.5$, $2$, $2.5$, $3$ con $f(x_i) = 1$, $0.6667$, $0.5$, $0.4$, $0.3333$.
  3. Aplicamos la fórmula con coeficientes $1, 4, 2, 4, 1$: $$S_4 = \frac{1}{6}\big[1 + 4(0.6667) + 2(0.5) + 4(0.4) + 0.3333\big] = \frac{1}{6}\,(1 + 2.6667 + 1 + 1.6 + 0.3333) = \frac{6.6}{6} = 1.1000$$
  4. Valor exacto: $\ln 3 \approx 1.0986$.
  5. Error absoluto: $|1.1 - 1.0986| \approx 0.0014$ ($0.13\,\%$). Con solo 4 subintervalos, mucho mejor que Riemann con 5 (ejemplo I.2).

$S_4 = 1.1000$ frente al exacto $\ln 3 \approx 1.0986$.
