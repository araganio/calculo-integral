Sumas de Riemann

La idea más básica para calcular el área bajo una curva: llenarla con rectángulos y sumar sus áreas. Entre más rectángulos, mejor la aproximación.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Queremos aproximar $\displaystyle\int_a^b f(x)\,dx$. Dividimos el intervalo $[a,b]$ en $n$ subintervalos del mismo ancho:

$$\Delta x = \frac{b-a}{n}, \qquad x_i = a + i\,\Delta x \quad (i = 0, 1, \dots, n)$$

Sobre cada subintervalo $[x_{i-1}, x_i]$ levantamos un rectángulo de base $\Delta x$. Lo que cambia entre un tipo de suma y otro es dónde se mide la altura:

  • Suma izquierda — altura en el extremo izquierdo: $$L_n = \Delta x\,\big[f(x_0) + f(x_1) + \cdots + f(x_{n-1})\big] = \Delta x \sum_{i=0}^{n-1} f(x_i)$$
  • Suma derecha — altura en el extremo derecho: $$R_n = \Delta x\,\big[f(x_1) + f(x_2) + \cdots + f(x_n)\big] = \Delta x \sum_{i=1}^{n} f(x_i)$$
  • Suma de punto medio — altura en el centro $\bar x_i = \frac{x_{i-1}+x_i}{2}$: $$M_n = \Delta x \sum_{i=1}^{n} f(\bar x_i)$$

La integral definida es el límite de estas sumas cuando el número de rectángulos crece sin límite:

$$\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x$$
Si $f$ es creciente, la suma izquierda se queda corta ($L_n$ subestima) y la derecha se pasa ($R_n$ sobreestima). Si $f$ es decreciente ocurre lo contrario. Compruébalo con $x^2$ y con $1/x$ en el visualizador.

3 Ejemplos resueltos paso a paso

Ejemplo I.1 — $\displaystyle\int_0^2 x^2\,dx$ con $n = 4$

  1. Ancho de cada subintervalo: $\Delta x = \dfrac{2-0}{4} = 0.5$.
  2. Nodos: $x_0=0$, $x_1=0.5$, $x_2=1$, $x_3=1.5$, $x_4=2$ con valores $f(x_i)$: $0$, $0.25$, $1$, $2.25$, $4$.
  3. Suma izquierda (usa $x_0$ a $x_3$): $$L_4 = 0.5\,(0 + 0.25 + 1 + 2.25) = 0.5 \cdot 3.5 = 1.75$$
  4. Suma derecha (usa $x_1$ a $x_4$): $$R_4 = 0.5\,(0.25 + 1 + 2.25 + 4) = 0.5 \cdot 7.5 = 3.75$$
  5. Punto medio: $\bar x_i = 0.25$, $0.75$, $1.25$, $1.75$ con $f(\bar x_i) = 0.0625$, $0.5625$, $1.5625$, $3.0625$: $$M_4 = 0.5\,(0.0625 + 0.5625 + 1.5625 + 3.0625) = 0.5 \cdot 5.25 = 2.625$$
  6. Valor exacto con el TFC: $$\int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} \approx 2.6667$$

$L_4 = 1.75$ (se queda corta), $R_4 = 3.75$ (se pasa), $M_4 = 2.625$ (error de solo $0.0417$). Exacto: $\frac{8}{3} \approx 2.6667$.

Ejemplo I.2 — $\displaystyle\int_1^3 \frac{1}{x}\,dx$ con $n = 5$

  1. Ancho: $\Delta x = \dfrac{3-1}{5} = 0.4$.
  2. Nodos: $1$, $1.4$, $1.8$, $2.2$, $2.6$, $3$ con $f(x_i) = 1$, $0.7143$, $0.5556$, $0.4545$, $0.3846$, $0.3333$.
  3. Suma izquierda: $$L_5 = 0.4\,(1 + 0.7143 + 0.5556 + 0.4545 + 0.3846) = 0.4 \cdot 3.1090 = 1.2436$$
  4. Suma derecha: $$R_5 = 0.4\,(0.7143 + 0.5556 + 0.4545 + 0.3846 + 0.3333) = 0.4 \cdot 2.4423 = 0.9769$$
  5. Punto medio: $\bar x_i = 1.2$, $1.6$, $2$, $2.4$, $2.8$ con $f(\bar x_i) = 0.8333$, $0.625$, $0.5$, $0.4167$, $0.3571$: $$M_5 = 0.4 \cdot 2.7321 = 1.0929$$
  6. Valor exacto: $$\int_1^3 \frac{dx}{x} = \big[\ln x\big]_1^3 = \ln 3 - \ln 1 = \ln 3 \approx 1.0986$$

Como $1/x$ es decreciente, ahora $L_5 = 1.2436$ se pasa y $R_5 = 0.9769$ se queda corta. $M_5 = 1.0929$ es la mejor (error $0.0058$).
