Módulo 16 · Fase 3 · Integral indefinida

Integrales Irracionales

Cuando el integrando tiene raíces de $x$ (o de una expresión lineal), un cambio de variable bien elegido las elimina y deja una integral racional.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Caso 1 · potencias de $x$ dentro de radicales

Si aparecen $\sqrt[m_1]{x}, \sqrt[m_2]{x}, \dots$, se hace el cambio

$$x = t^{m}, \qquad dx = m\,t^{m-1}\,dt, \qquad m = \operatorname{mcm}(m_1, m_2, \dots)$$

Así cada raíz se convierte en una potencia entera de $t$. Por ejemplo, con $\sqrt{x}$ y $\sqrt[3]{x}$ se usa $m = 6$ y $x = t^6$.

Caso 2 · radical de una expresión lineal

Si aparece $\sqrt[n]{ax + b}$, se toma $t = \sqrt[n]{ax + b}$; se despeja $x = \dfrac{t^n - b}{a}$ y $dx = \dfrac{n\,t^{n-1}}{a}\,dt$.

Pasos

  1. Elige la sustitución y calcula $dx$.
  2. Reescribe toda la integral en $t$: queda una función racional.
  3. Si el grado del numerador es mayor o igual que el del denominador, divide; si no, fracciones parciales (módulo 15).
  4. Integra y regresa a $x$ con $t = x^{1/m}$ (o con $t = \sqrt[n]{ax+b}$).
No olvides el $dx$: es el paso donde más se falla. Si $x = t^6$, entonces $dx = 6t^5\,dt$ y debe aparecer en la integral.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Las integrales irracionales se vuelven racionales con una sustitución, pero la antiderivada final vuelve a tener raíces. Comprueba con la tangente que $F'$ sigue siendo $f$.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo XVI.1 — $\displaystyle\int \frac{dx}{\sqrt{x} + \sqrt[3]{x}}$

  1. Los índices son 2 y 3, y $\operatorname{mcm}(2,3) = 6$. Hacemos $x = t^6$, $dx = 6t^5\,dt$; entonces $\sqrt{x} = t^3$ y $\sqrt[3]{x} = t^2$.
  2. Sustituimos: $$\int \frac{6t^5}{t^3 + t^2}\,dt = 6\int \frac{t^3}{t+1}\,dt$$
  3. El grado del numerador es mayor: dividimos, $\dfrac{t^3}{t+1} = t^2 - t + 1 - \dfrac{1}{t+1}$.
  4. Integramos: $$6\left[\frac{t^3}{3} - \frac{t^2}{2} + t - \ln|t+1|\right] = 2t^3 - 3t^2 + 6t - 6\ln|t+1|$$
  5. Volvemos a $x$ con $t = \sqrt[6]{x}$: $$2\sqrt{x} - 3\sqrt[3]{x} + 6\sqrt[6]{x} - 6\ln\left(\sqrt[6]{x} + 1\right) + C$$

$\displaystyle 2\sqrt{x} - 3\sqrt[3]{x} + 6\sqrt[6]{x} - 6\ln\left(\sqrt[6]{x} + 1\right) + C$

Ejemplo XVI.2 — $\displaystyle\int \frac{x}{\sqrt{x+1}}\,dx$

  1. Elegimos $t = \sqrt{x+1}$. Entonces $x = t^2 - 1$ y $dx = 2t\,dt$.
  2. Sustituimos: $$\int \frac{t^2 - 1}{t}\cdot 2t\,dt = 2\int (t^2 - 1)\,dt$$
  3. Integramos: $2\left(\dfrac{t^3}{3} - t\right) = \dfrac{2t^3}{3} - 2t$.
  4. Volvemos a $x$: $$\int \frac{x}{\sqrt{x+1}}\,dx = \frac23(x+1)^{3/2} - 2\sqrt{x+1} + C$$

$\displaystyle \frac23(x+1)^{3/2} - 2\sqrt{x+1} + C$

Ejemplo XVI.3 — $\displaystyle\int \frac{dx}{1 + \sqrt{x}}$

  1. Elegimos $t = \sqrt{x}$, entonces $x = t^2$ y $dx = 2t\,dt$.
  2. Sustituimos: $$\int \frac{2t}{1+t}\,dt = 2\int\left(1 - \frac{1}{1+t}\right)dt$$ (porque $\dfrac{t}{1+t} = 1 - \dfrac{1}{1+t}$).
  3. Integramos: $2t - 2\ln(1+t)$.
  4. Volvemos a $x$: $$\int \frac{dx}{1+\sqrt{x}} = 2\sqrt{x} - 2\ln\left(1 + \sqrt{x}\right) + C$$

$\displaystyle 2\sqrt{x} - 2\ln\left(1 + \sqrt{x}\right) + C$
