Integrales Exponenciales

La función $e^x$ es su propia derivada, así que también es su propia integral. Con una sustitución sencilla se resuelven $e^{u}$ y $a^{u}$.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Las dos fórmulas básicas, con $u = g(x)$ y $du = g'(x)\,dx$:

$$\int e^{u}\,du = e^{u} + C \qquad\qquad \int a^{u}\,du = \frac{a^{u}}{\ln a} + C \quad (a > 0,\ a \neq 1)$$

Si el exponente es lineal, $\displaystyle\int e^{kx}\,dx = \frac{e^{kx}}{k} + C$: dividimos entre la derivada del exponente.

Para $a^x$: $a^x = e^{x\ln a}$, por eso aparece $\ln a$ en el denominador. Con $a = e$ da $\ln e = 1$ y se recupera la primera fórmula.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Observa que la exponencial crece muy rápido: la antiderivada de $e^{3x}$ es $e^{3x}/3$, una curva parecida pero 3 veces más "plana". La tangente a $F$ siempre tiene pendiente $f(x)$.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo VIII.1 — $\displaystyle\int e^{3x}\,dx$

  1. Elegimos $u = 3x$, entonces $du = 3\,dx$ y $dx = \tfrac13\,du$.
  2. Sustituimos: $$\frac13\int e^{u}\,du = \frac13\,e^{u}$$
  3. Volvemos a $x$: $\displaystyle\int e^{3x}\,dx = \frac{e^{3x}}{3} + C$.
  4. Comprobación: $\dfrac{d}{dx}\dfrac{e^{3x}}{3} = e^{3x}$ ✔

$\displaystyle \frac{e^{3x}}{3} + C$

Ejemplo VIII.2 — $\displaystyle\int x\,e^{x^2}\,dx$

  1. Elegimos $u = x^2$, así $du = 2x\,dx$ y $x\,dx = \tfrac12\,du$.
  2. Sustituimos: $$\frac12\int e^{u}\,du = \frac12\,e^{u}$$
  3. Volvemos a $x$: $\displaystyle\int x\,e^{x^2}\,dx = \frac{e^{x^2}}{2} + C$.
  4. Comprobación: $\dfrac{d}{dx}\dfrac{e^{x^2}}{2} = \dfrac{2x\,e^{x^2}}{2} = x\,e^{x^2}$ ✔

$\displaystyle \frac{e^{x^2}}{2} + C$
