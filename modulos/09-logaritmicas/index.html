Integrales Logarítmicas

Cuando el numerador es (un múltiplo de) la derivada del denominador, la integral es un logaritmo: $\int \frac{du}{u} = \ln|u| + C$.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

La integral que completa la regla de la potencia (el caso $n = -1$):

$$\int \frac{du}{u} = \ln|u| + C \qquad\Longrightarrow\qquad \int \frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + C$$

Cómo reconocerla

  • Mira el denominador y deriva mentalmente: si el numerador es esa derivada (salvo una constante), el resultado es $\ln|\text{denominador}|$.
  • Si falta una constante, se compensa fuera de la integral (como en una sustitución).
  • El valor absoluto es necesario porque $\ln$ solo existe para positivos, pero $\dfrac{1}{u}$ está definida también para $u < 0$.
Caso especial: $\displaystyle\int \frac{dx}{x\ln x} = \ln|\ln x| + C$, con $u = \ln x$ y $du = \dfrac{dx}{x}$.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Fíjate en las asíntotas: $f$ no está definida donde se anula el denominador, y $F = \ln|\cdot|$ tampoco. El valor absoluto permite integrar a ambos lados de la asíntota.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo IX.1 — $\displaystyle\int \frac{dx}{2x+1}$

  1. Elegimos $u = 2x + 1$, entonces $du = 2\,dx$ y $dx = \tfrac12\,du$.
  2. Sustituimos: $$\frac12\int \frac{du}{u} = \frac12\ln|u|$$
  3. Volvemos a $x$: $\displaystyle\int \frac{dx}{2x+1} = \frac12\ln|2x+1| + C$.
  4. Comprobación: $\dfrac{d}{dx}\left(\dfrac12\ln|2x+1|\right) = \dfrac12\cdot\dfrac{2}{2x+1} = \dfrac{1}{2x+1}$ ✔

$\displaystyle \frac12\ln|2x+1| + C$

Ejemplo IX.2 — $\displaystyle\int \frac{x^2}{x^3+1}\,dx$

  1. La derivada del denominador es $3x^2$; el numerador es $x^2$, o sea un tercio de ella.
  2. Elegimos $u = x^3 + 1$, así $du = 3x^2\,dx$ y $x^2\,dx = \tfrac13\,du$.
  3. Sustituimos: $$\frac13\int \frac{du}{u} = \frac13\ln|u|$$
  4. Volvemos a $x$: $\displaystyle\int \frac{x^2}{x^3+1}\,dx = \frac13\ln|x^3+1| + C$.
  5. Comprobación: $\dfrac{d}{dx}\left(\dfrac13\ln|x^3+1|\right) = \dfrac13\cdot\dfrac{3x^2}{x^3+1} = \dfrac{x^2}{x^3+1}$ ✔

$\displaystyle \frac13\ln|x^3+1| + C$
