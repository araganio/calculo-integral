Módulo 18 · Fase 3 · Integral indefinida

Sustitución Universal

Si el integrando es una expresión racional de $\sin x$ y $\cos x$, el cambio $z = \tan\frac{x}{2}$ lo convierte en una función racional de $z$. Se llama "universal" porque funciona siempre.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Con $z = \tan\dfrac{x}{2}$ (es decir, $x = 2\arctan z$) se cumple:

$$\sin x = \frac{2z}{1 + z^2}, \qquad \cos x = \frac{1 - z^2}{1 + z^2}, \qquad dx = \frac{2\,dz}{1 + z^2}$$

Pasos

  1. Sustituye $\sin x$, $\cos x$ y $dx$ con las fórmulas de arriba.
  2. Simplifica: queda una función racional de $z$.
  3. Intégrala (fracciones parciales, módulo 15).
  4. Regresa a $x$ con $z = \tan\dfrac{x}{2}$.
Cuándo usarla: es el último recurso. Si la integral se resuelve con una sustitución $u = \sin x$ o $u = \cos x$, o con identidades (módulo 10), esos caminos son más cortos. La universal es la que siempre funciona para $\dfrac{1}{a + b\sin x + c\cos x}$.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Estas integrales dan resultados con $\tan\frac{x}{2}$. Observa que las gráficas tienen asíntotas donde $x$ es múltiplo de $\pi$, que es donde $z = \tan\frac{x}{2}$ deja de existir.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo XVIII.1 — $\displaystyle\int \frac{dx}{1 + \cos x}$

  1. Sustituimos: $1 + \cos x = 1 + \dfrac{1 - z^2}{1 + z^2} = \dfrac{2}{1 + z^2}$.
  2. La integral queda: $$\int \frac{2\,dz}{1+z^2}\cdot\frac{1+z^2}{2} = \int dz = z$$
  3. Volvemos a $x$: $\displaystyle\int \frac{dx}{1 + \cos x} = \tan\frac{x}{2} + C$.
  4. Comprobación: $\dfrac{d}{dx}\tan\dfrac{x}{2} = \dfrac12\sec^2\dfrac{x}{2} = \dfrac{1}{1 + \cos x}$ ✔ (porque $1 + \cos x = 2\cos^2\frac{x}{2}$)

$\displaystyle \tan\frac{x}{2} + C$

Ejemplo XVIII.2 — $\displaystyle\int \frac{dx}{\sin x}$

  1. Sustituimos: $\sin x = \dfrac{2z}{1+z^2}$ y $dx = \dfrac{2\,dz}{1+z^2}$.
  2. La integral queda: $$\int \frac{2\,dz}{1+z^2}\cdot\frac{1+z^2}{2z} = \int \frac{dz}{z} = \ln|z|$$
  3. Volvemos a $x$: $\displaystyle\int \frac{dx}{\sin x} = \ln\left|\tan\frac{x}{2}\right| + C$ (es la integral de $\csc x$).

$\displaystyle \ln\left|\tan\frac{x}{2}\right| + C$

Ejemplo XVIII.3 — $\displaystyle\int \frac{dx}{3 + 5\sin x}$

  1. Sustituimos: $3 + 5\sin x = 3 + \dfrac{10z}{1+z^2} = \dfrac{3z^2 + 10z + 3}{1 + z^2}$.
  2. La integral queda: $$\int \frac{2\,dz}{3z^2 + 10z + 3} = 2\int \frac{dz}{(3z+1)(z+3)}$$
  3. Fracciones parciales (caso 1): $\dfrac{1}{(3z+1)(z+3)} = \dfrac18\left(\dfrac{3}{3z+1} - \dfrac{1}{z+3}\right)$.
  4. Integramos: $$2\cdot\frac18\Big[\ln|3z+1| - \ln|z+3|\Big] = \frac14\ln\left|\frac{3z+1}{z+3}\right|$$
  5. Volvemos a $x$: $$\int \frac{dx}{3 + 5\sin x} = \frac14\ln\left|\frac{3\tan\frac{x}{2} + 1}{\tan\frac{x}{2} + 3}\right| + C$$

$\displaystyle \frac14\ln\left|\frac{3\tan\frac{x}{2} + 1}{\tan\frac{x}{2} + 3}\right| + C$
