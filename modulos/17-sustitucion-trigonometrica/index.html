Módulo 17 · Fase 3 · Integral indefinida

Sustitución Trigonométrica

Cuando el integrando contiene $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$ o $\sqrt{x^2 - a^2}$, se reemplaza $x$ por una función trigonométrica para que la raíz desaparezca con una identidad pitagórica.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

ExpresiónSustituciónResultado de la raíz
$\sqrt{a^2 - x^2}$$x = a\sin\theta$,  $dx = a\cos\theta\,d\theta$$a\cos\theta$
$\sqrt{a^2 + x^2}$$x = a\tan\theta$,  $dx = a\sec^2\theta\,d\theta$$a\sec\theta$
$\sqrt{x^2 - a^2}$$x = a\sec\theta$,  $dx = a\sec\theta\tan\theta\,d\theta$$a\tan\theta$

Salen de $1 - \sin^2\theta = \cos^2\theta$, $1 + \tan^2\theta = \sec^2\theta$ y $\sec^2\theta - 1 = \tan^2\theta$.

Pasos

  1. Identifica la forma y el valor de $a$.
  2. Sustituye $x$ y $dx$; la raíz se convierte en una expresión trigonométrica.
  3. Integra respecto a $\theta$ (módulo 10: potencias de seno y coseno).
  4. Regresa a $x$ con un triángulo rectángulo: dibuja el ángulo $\theta$ con los lados que da la sustitución y lee de ahí el seno, el coseno o la tangente.
Tip: si la integral tiene un trinomio $ax^2 + bx + c$ bajo la raíz, primero completa el cuadrado (módulo 13) y luego aplica la sustitución.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Las tres antiderivadas mezclan funciones algebraicas con arcoseno o arcosecante. Comprueba con la tangente que $F'$ coincide con $f$ en cada punto.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo XVII.1 — $\displaystyle\int \sqrt{4 - x^2}\,dx$

  1. Forma $\sqrt{a^2 - x^2}$ con $a = 2$: $x = 2\sin\theta$, $dx = 2\cos\theta\,d\theta$ y $\sqrt{4 - x^2} = 2\cos\theta$.
  2. Sustituimos: $$\int 2\cos\theta\cdot 2\cos\theta\,d\theta = 4\int \cos^2\theta\,d\theta = 2\int (1 + \cos 2\theta)\,d\theta$$
  3. Integramos: $2\theta + \sin 2\theta = 2\theta + 2\sin\theta\cos\theta$.
  4. Triángulo: $\sin\theta = \dfrac{x}{2}$, $\cos\theta = \dfrac{\sqrt{4-x^2}}{2}$ y $\theta = \arcsin\dfrac{x}{2}$.
  5. Resultado: $$\int \sqrt{4 - x^2}\,dx = 2\arcsin\frac{x}{2} + \frac{x\sqrt{4 - x^2}}{2} + C$$ (es el área de un semicírculo: por eso $\int_{-2}^{2} = 2\pi$).

$\displaystyle \frac{x\sqrt{4 - x^2}}{2} + 2\arcsin\frac{x}{2} + C$

Ejemplo XVII.2 — $\displaystyle\int \frac{dx}{x^2\sqrt{x^2 + 4}}$

  1. Forma $\sqrt{x^2 + a^2}$ con $a = 2$: $x = 2\tan\theta$, $dx = 2\sec^2\theta\,d\theta$ y $\sqrt{x^2+4} = 2\sec\theta$.
  2. Sustituimos: $$\int \frac{2\sec^2\theta}{4\tan^2\theta\cdot 2\sec\theta}\,d\theta = \frac14\int \frac{\sec\theta}{\tan^2\theta}\,d\theta = \frac14\int \frac{\cos\theta}{\sin^2\theta}\,d\theta$$
  3. Con $u = \sin\theta$: $\displaystyle\frac14\int u^{-2}\,du = -\frac{1}{4\sin\theta}$.
  4. Triángulo: $\tan\theta = \dfrac{x}{2}$, así que $\sin\theta = \dfrac{x}{\sqrt{x^2+4}}$.
  5. Resultado: $$\int \frac{dx}{x^2\sqrt{x^2+4}} = -\frac{\sqrt{x^2+4}}{4x} + C$$

$\displaystyle -\frac{\sqrt{x^2+4}}{4x} + C$

Ejemplo XVII.3 — $\displaystyle\int \frac{\sqrt{x^2 - 4}}{x}\,dx$ (para $x > 2$)

  1. Forma $\sqrt{x^2 - a^2}$ con $a = 2$: $x = 2\sec\theta$, $dx = 2\sec\theta\tan\theta\,d\theta$ y $\sqrt{x^2-4} = 2\tan\theta$.
  2. Sustituimos: $$\int \frac{2\tan\theta}{2\sec\theta}\cdot 2\sec\theta\tan\theta\,d\theta = 2\int \tan^2\theta\,d\theta = 2\int (\sec^2\theta - 1)\,d\theta$$
  3. Integramos: $2\tan\theta - 2\theta$.
  4. Triángulo: $\tan\theta = \dfrac{\sqrt{x^2-4}}{2}$ y $\theta = \operatorname{arcsec}\dfrac{x}{2}$.
  5. Resultado: $$\int \frac{\sqrt{x^2-4}}{x}\,dx = \sqrt{x^2 - 4} - 2\operatorname{arcsec}\frac{x}{2} + C$$

$\displaystyle \sqrt{x^2 - 4} - 2\operatorname{arcsec}\frac{x}{2} + C$
