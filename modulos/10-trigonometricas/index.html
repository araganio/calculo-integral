Integrales Trigonométricas

Integrales de potencias de seno, coseno y tangente. Con identidades trigonométricas y una sustitución se reducen a integrales directas.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Fórmulas de partida:

$$\int \sin u\,du = -\cos u + C \qquad \int \cos u\,du = \sin u + C \qquad \int \tan u\,du = -\ln|\cos u| + C$$

Estrategias

  • Potencia par de seno o coseno: baja el grado con las identidades $$\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}$$
  • Potencia impar: separa un factor y usa $\sin^2 x + \cos^2 x = 1$ para que quede $u = \cos x$ (o $u = \sin x$) con su derivada.
  • Tangente: $\tan x = \dfrac{\sin x}{\cos x}$ y se usa la sustitución $u = \cos x$.
Cuidado con el signo: si $u = \cos x$, entonces $du = -\sin x\,dx$. Ese signo menos es el error más común.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Compara $f$ con $F$: donde $F$ tiene un máximo o mínimo, $f$ cruza el eje $x$ (pendiente cero). Mueve el punto para verlo con la tangente.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo X.1 — $\displaystyle\int \sin^2 x\,dx$

  1. Bajamos el grado con la identidad del ángulo doble: $$\sin^2 x = \frac{1 - \cos 2x}{2}$$
  2. Integramos término a término: $$\int \frac{1 - \cos 2x}{2}\,dx = \frac{x}{2} - \frac12\cdot\frac{\sin 2x}{2}$$
  3. Resultado: $\displaystyle\int \sin^2 x\,dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$.
  4. Comprobación: $\dfrac{d}{dx}\left(\dfrac{x}{2} - \dfrac{\sin 2x}{4}\right) = \dfrac{1 - \cos 2x}{2} = \sin^2 x$ ✔

$\displaystyle \frac{x}{2} - \frac{\sin 2x}{4} + C$

Ejemplo X.2 — $\displaystyle\int \sin x\,\cos^2 x\,dx$

  1. Elegimos $u = \cos x$, entonces $du = -\sin x\,dx$ y $\sin x\,dx = -du$.
  2. Sustituimos: $$-\int u^2\,du = -\frac{u^3}{3}$$
  3. Volvemos a $x$: $\displaystyle\int \sin x\cos^2 x\,dx = -\frac{\cos^3 x}{3} + C$.
  4. Comprobación: $\dfrac{d}{dx}\left(-\dfrac{\cos^3 x}{3}\right) = -\cos^2 x\cdot(-\sin x) = \sin x\cos^2 x$ ✔

$\displaystyle -\frac{\cos^3 x}{3} + C$
