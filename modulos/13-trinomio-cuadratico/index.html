Módulo 13 · Fase 3 · Integral indefinida

Trinomio Cuadrático

Cuando el denominador (o la raíz) tiene un trinomio $ax^2 + bx + c$, se completa el cuadrado para llevarlo a una de las formas de los módulos 11 y 12.

1. Teoría 2. Visualizador 3. Ejemplos resueltos

1 Teoría

Completar el cuadrado consiste en reescribir el trinomio como un binomio al cuadrado más una constante:

$$x^2 + bx + c = \left(x + \frac{b}{2}\right)^2 + \left(c - \frac{b^2}{4}\right)$$

Pasos

  1. Si el coeficiente de $x^2$ no es 1, sácalo como factor (si es negativo, factoriza el signo menos).
  2. Completa el cuadrado y llama $u = x + \frac{b}{2}$, con $du = dx$.
  3. Según el signo del resultado, usa arcotangente ($u^2 + a^2$), arcoseno ($a^2 - u^2$ bajo raíz) o logaritmo ($u^2 - a^2$).
Ojo: si el trinomio tiene raíces reales, también se puede resolver con fracciones parciales; las dos vías dan el mismo resultado.

2 Visualizador interactivo: $f(x)$ y su antiderivada $F(x) + C$

Observa que el trinomio desplaza el centro de la curva: en $\frac{1}{x^2+2x+5}$ el máximo está en $x = -1$, justo el valor que aparece al completar el cuadrado.

La recta tangente a F en ese punto tiene pendiente f(x).

3 Ejemplos resueltos paso a paso

Ejemplo XIII.1 — $\displaystyle\int \frac{dx}{x^2 + 2x + 5}$

  1. Completamos el cuadrado: $x^2 + 2x + 5 = (x + 1)^2 + 4$.
  2. Sea $u = x + 1$ ($du = dx$) y $a = 2$: $$\int \frac{du}{u^2 + 4}$$
  3. Fórmula del arcotangente: $$\frac12\arctan\frac{u}{2}$$
  4. Volvemos a $x$: $\displaystyle\int \frac{dx}{x^2+2x+5} = \frac12\arctan\frac{x+1}{2} + C$.
  5. Comprobación: $\dfrac{d}{dx}\left(\dfrac12\arctan\dfrac{x+1}{2}\right) = \dfrac12\cdot\dfrac{1/2}{1 + (x+1)^2/4} = \dfrac{1}{(x+1)^2 + 4}$ ✔

$\displaystyle \frac12\arctan\frac{x+1}{2} + C$

Ejemplo XIII.2 — $\displaystyle\int \frac{dx}{\sqrt{3 - 2x - x^2}}$

  1. El coeficiente de $x^2$ es negativo: $3 - 2x - x^2 = -(x^2 + 2x) + 3 = -\big[(x+1)^2 - 1\big] + 3 = 4 - (x+1)^2$.
  2. Sea $u = x + 1$ ($du = dx$) y $a = 2$: $$\int \frac{du}{\sqrt{4 - u^2}}$$
  3. Fórmula del arcoseno: $$\arcsin\frac{u}{2}$$
  4. Volvemos a $x$: $\displaystyle\int \frac{dx}{\sqrt{3-2x-x^2}} = \arcsin\frac{x+1}{2} + C$.
  5. Dominio: $4 - (x+1)^2 > 0$ exige $-3 < x < 1$.

$\displaystyle \arcsin\frac{x+1}{2} + C$

Ejemplo XIII.3 — $\displaystyle\int \frac{dx}{x^2 - 4x + 3}$

  1. Completamos el cuadrado: $x^2 - 4x + 3 = (x - 2)^2 - 1$.
  2. Sea $u = x - 2$ ($du = dx$) y $a = 1$: $$\int \frac{du}{u^2 - 1}$$
  3. Como $\dfrac{1}{u^2 - a^2} = -\dfrac{1}{a^2 - u^2}$, la fórmula del módulo 12 da $$\frac{1}{2a}\ln\left|\frac{u - a}{u + a}\right| = \frac12\ln\left|\frac{u - 1}{u + 1}\right|$$
  4. Volvemos a $x$: $\displaystyle\int \frac{dx}{x^2-4x+3} = \frac12\ln\left|\frac{x - 3}{x - 1}\right| + C$.
  5. Comprobación con fracciones parciales: $\dfrac{1}{(x-1)(x-3)} = \dfrac12\left(\dfrac{1}{x-3} - \dfrac{1}{x-1}\right)$ ✔

$\displaystyle \frac12\ln\left|\frac{x - 3}{x - 1}\right| + C$
